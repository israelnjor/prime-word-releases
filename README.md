# Prime Word

A word processor for Windows by Prime Productivity: works offline, opens and saves Word documents
faithfully, and turns PDFs into editable documents.

## Download

Get the latest installer from **[Releases](../../releases/latest)**: `PrimeWord_<version>_x64-setup.exe`.

Windows may warn that the installer is from an unknown publisher (it is not code-signed yet): choose
**More info → Run anyway**. Once installed, Prime Word updates itself.

## Feedback
